# Step 0 — Warm-up + dashboard

> **Time budget:** 3 minutes • **Skill:** `/ai-start`

## The command

Abre tu IDE/agente en la carpeta donde ejecutaste `ai-eng install` y escribe en el chat:

```text
/ai-start
```

## Qué debe pasar

Verás un dashboard con:

- Rama actual.
- Spec activo, si existe.
- Plan activo, si existe.
- Últimos commits.
- Siguiente acción recomendada.

## Qué mirar

- Si dice que no hay spec activo, perfecto: estás listo para `/ai-brainstorm`.
- Si `/ai-start` no existe o no aparece, seguramente abriste el agente en otra carpeta. Vuelve a la carpeta donde hiciste `ai-eng install` y ejecuta `ai-eng doctor`.
