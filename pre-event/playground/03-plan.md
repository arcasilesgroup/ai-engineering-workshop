# Step 3 — Planifica

> **Time budget:** 7 minutes • **Skill:** `/ai-plan`

## The command

```text
/ai-plan
```

## Qué debe producir

Un plan de ejecución con tareas pequeñas. En proyectos con código, debería separar RED/GREEN/REFACTOR cuando aplique.

Busca algo parecido a:

```markdown
# Plan — spec-NNN — <title>

- [ ] T-1 — Preparar prueba o verificación
- [ ] T-2 — Implementar el cambio mínimo
- [ ] T-3 — Ejecutar checks y ajustar documentación
```

## Regla

No sigas a `/ai-build` hasta que el plan tenga sentido. Si el plan es demasiado grande, pide reducir scope.
