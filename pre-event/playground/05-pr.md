# Step 5 — Prepara commit/PR

> **Time budget:** 6 minutes • **Skill:** `/ai-pr`

## Ruta local recomendada para el pre-evento

Si solo estás jugando en una carpeta de prueba y no quieres empujar a GitHub:

```text
/ai-pr --only commit
```

## Ruta completa si tienes remoto

Si tu proyecto tiene remoto y quieres practicar el flujo completo:

```text
/ai-pr
```

## Qué debe pasar

- Revisa cambios.
- Ejecuta gates.
- Crea commit convencional.
- Si hay remoto, puede crear o actualizar PR.
