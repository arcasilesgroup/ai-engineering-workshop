# Step 7 — Entiende lo cambiado

> **Time budget:** 2 minutes • **Skill:** `/ai-explain`

## The command

```text
/ai-explain "What changed in this playground session, why did we make those choices, and what should I understand before touching this project again?"
```

También puedes apuntar a un archivo concreto:

```text
/ai-explain <path/to/file>
```

## Por qué importa

La IA puede generar cambios rápido. Tú sigues siendo responsable de entenderlos. `/ai-explain` cierra el loop: te devuelve el mapa del cambio con referencias al proyecto.

## Has terminado el playground

Has practicado la cadena base:

```text
/ai-start → /ai-explore → /ai-brainstorm → /ai-plan → /ai-build → /ai-pr → /ai-review → /ai-explain
```

Ahora repite lo mismo en un proyecto real pequeño.
