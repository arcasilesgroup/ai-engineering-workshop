# Pre-event Playground

> Práctica opcional para jugar con ai-engineering antes del evento. Usa cualquier carpeta o proyecto de prueba donde hayas ejecutado `ai-eng install`.

## Antes de empezar

- Has completado [pre-event step 1](../01-install-ai-engineering.md).
- Estás dentro de la carpeta donde quieres practicar.
- Ya has ejecutado ahí:

  ```bash
  ai-eng install
  ai-eng doctor
  ```

- Tu IDE/agente está abierto con **esa misma carpeta** como raíz.
- Los comandos `/ai-start`, `/ai-brainstorm`, `/ai-plan`, etc. se escriben en el chat del agente, no en la terminal normal.

## Qué vas a practicar

No hay un proyecto obligatorio. Elige un cambio pequeño y seguro para tu carpeta de prueba. Ejemplos:

- Crear o mejorar un `README.md`.
- Añadir un script pequeño.
- Ordenar una estructura inicial de carpetas.
- Añadir un test mínimo si tu proyecto ya tiene código.
- Pedirle al agente que explore el repo y proponga un MVP pequeño.

El objetivo no es construir algo grande. El objetivo es entender la cadena:

```text
/ai-start → /ai-explore → /ai-brainstorm → /ai-plan → /ai-build → /ai-review → /ai-explain
```
