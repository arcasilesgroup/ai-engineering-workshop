## Qué encontrarás aquí el 25 de mayo

El día del workshop subiremos aquí los ejercicios reales:

1. Problemas de proyecto para practicar ai-engineering con casos útiles, no demos artificiales.
2. Guías paso a paso para usar `/ai-explore`, `/ai-brainstorm`, `/ai-plan`, `/ai-build`, `/ai-review`, `/ai-pr` y `/ai-explain` sobre esos problemas.
3. El reto final: **La Batalla de las IAs**, preparado como ejercicio con criterios de demo y assets.

## Qué hacer mientras tanto

Llega al evento con esto funcionando:

```bash
ai-eng version
# entra en la carpeta donde hayas ejecutado ai-eng install
ai-eng doctor
```

Y abre tu IDE/agente dentro de esa misma carpeta para comprobar:

```text
/ai-start
```

Si eso funciona, el 25 podrás empezar directamente con el workshop.
