## Uso recomendado con ai-engineering

1. Copia este reto dentro del repo o app que vayas a construir.
2. Ejecuta `ai-eng install . --surface <tu-surface>` si el proyecto aún no está gobernado.
3. Abre tu agente de IA en la raíz del proyecto.
4. Ejecuta `/ai-brainstorm` con el reto elegido.
5. No empieces a construir hasta tener spec y plan aprobados.
